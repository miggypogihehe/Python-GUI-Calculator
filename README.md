calculator_na_maangas

This Python program is a Simple Calculator Application created using the Tkinter library. 
It allows users to perform basic mathematical operations such as addition, subtraction, multiplication, and division. It also includes buttons for clearing the display, deleting the last input, and calculating results. 
The program uses Python's AST module to safely evaluate mathematical expressions and provides a simple, user-friendly graphical interface.
